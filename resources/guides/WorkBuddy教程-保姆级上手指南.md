## 一、这是什么工具？

**WorkBuddy** 是腾讯出品的AI原生桌面智能体工作台，俗称"小龙虾"。你可以把它理解为：**一个住在你电脑里的AI员工，你说话它干活。**

与ChatGPT等对话式AI最大的区别：WorkBuddy**能直接操作你的电脑**——帮你整理文件、做报表、写PPT、发邮件、管理日程，全程不用你动手。

### 核心能力

| 能力 | 说明 |
|------|------|
| 一句话指挥 | 自然语言描述任务，AI自动拆解并执行 |
| 操作电脑文件 | 直接读取、编辑、归类你桌面上的文件 |
| 生成文档/表格/PPT | 从原始数据到完整报告全自动 |
| 远程控制 | 人在外面，手机发消息让电脑干活 |
| 定时自动化 | 设置一个任务让它每天自动跑 |
| 多模型切换 | 腾讯混元、DeepSeek、GLM、Kimi一键切换 |

### 关键数据

- **上线时间**：2026年3月9日，腾讯云CodeBuddy团队推出
- **用户规模**：上线4个月注册用户突破820万，PC端月访问量885万
- **国内排名**：AI原生办公智能体排名第一

## 二、安装与设置（5分钟上手）

### 2.1 下载安装

```text
1. 打开官网 workbuddy.cn
2. 点击"免费下载"，选择你的系统版本（macOS / Windows）
3. 双击安装包，按照提示完成安装
4. 启动WorkBuddy，用微信扫码登录（最简单的方式）
```

> 首次启动时，系统会弹出权限请求——允许WorkBuddy访问你的文件、屏幕和网络，这些都是它帮你干活必需的权限。

安装完成后，WorkBuddy会弹出新手引导教程，建议完整走一遍（约3分钟）。它会教你：

- 如何下达第一条指令
- 如何查看执行结果
- 如何安装技能包

### 2.3 连接微信（强烈推荐）

WorkBuddy支持微信远程控制，这是它最实用的功能之一：

```text
1. 在WorkBuddy设置中找到「Claw远程控制」

3. 绑定成功后，你的手机上会多一个"AI同事"好友
4. 以后你可以通过微信给它发消息远程指挥电脑
```

## 四、正确使用姿势（精华）

### 4.1 指令越具体，结果越好

**错误示范**：
```
帮我做个报表
```

**正确示范**：
```
打开桌面上的"2026年Q1销售数据.xlsx"，
计算每个产品线的一季度总营收，
按营收从高到低排序，
生成一张柱状图，
把结果保存到桌面上的"Q1分析报告.pptx"里。
```

> 原理：WorkBuddy就像一个新来的同事，你说得越清楚，它做得越到位。

### 4.2 复杂任务的正确打开方式

当任务比较复杂时，不要一句话扔给它，而是分步骤说：

**第一步**：先让AI出方案
```
帮我规划一下"做一份年度总结PPT"的步骤，我先看看你的思路
```

**第二步**：确认方案后让AI开始执行
```
方案没问题，开始执行第一步：分析数据
```

**第三步**：每完成一步检查一次
```
第二步的图表做好了？我看看效果...可以，继续下一步
```

### 4.3 定时任务：让AI每天自动干活

这是WorkBuddy对OPC最实用的功能——设置一次，每天都自动运行：

```text
设置方法：
1. 输入指令时加上「每天/每周/每月」
2. 指定具体时间和动作

# 例子：
"每天早上9点，自动导出昨天的订单数据，生成Excel发到我微信"
"每周五下午5点，汇总本周工作生成周报"
"每月1号，分析上个月的营收数据生成趋势图"
```

### 4.4 多模型切换

WorkBuddy支持切换不同的AI模型，不同任务可以选不同的"大脑"：

| 模型 | 擅长 | 适合场景 |
|------|------|---------|
| 腾讯混元 | 中文理解、腾讯生态 | 微信公众号内容、办公文档 |
| DeepSeek | 逻辑推理、代码生成 | 数据分析、复杂计算 |
| GLM（智谱） | 知识问答 | 行业调研、知识检索 |
| Kimi | 长文本处理 | 合同审核、长文档分析 |

> 在WorkBuddy设置中一键切换，不用重新安装任何东西。

## 五、实战场景（含完整指令）

### 场景1：每周周报自动化（OPC最实用）

这是OPC最常遇到的需求——每周向客户或团队汇报工作进展。

**完整指令**：
```
帮我设计一个每周周报的自动生成流程，要求如下：

1. 数据来源：
   - 读取桌面上的"本周工作记录.xlsx"
   - 统计本周完成的项
   - 提取重点工作内容

2. 周报结构：
   - 本周完成事项（bullet point）
   - 核心数据指标（用表格展示）
   - 遇到的问题和解决方案
   - 下周计划（3-5项）

3. 输出格式：
   - 生成 Word 文档，排版简洁专业
   - 保存到桌面 -> 周报/ 文件夹
   - 文件名格式：周报_YYYYMMDD.docx

4. 自动发送：
   - 通过微信发给我
   - 每周五下午5点执行

请先输出方案，我确认后再设置定时任务。
```

**执行效率对比**：
```
手动做：每周花30-60分钟整理、写、排版
用WorkBuddy：说一次，之后每周自动完成
```

### 场景2：用Excel数据一键做PPT汇报

你有一个Excel数据表，需要做成PPT向客户或投资人汇报。

**完整指令**：
```
基于桌面上的"2026上半年营收数据.xlsx"，
生成一份专业的PPT汇报文件。

具体要求：

1. 封面页
   - 标题：2026上半年营收复盘与下半年展望
   - 公司/团队名称自动提取

2. 数据概览页
   - 总营收、同比增长率、环比增长率
   - 用大号数字+简洁图标展示

3. 趋势分析页
   - 月度营收趋势折线图
   - 标注峰值和谷值

4. 产品分析页
   - 各产品线营收占比的饼图
   - 增长最快和下降最多的产品

5. 总结与计划页
   - 核心结论（3-5条）
   - 下半年重点方向

设计要求：
- 配色：蓝色商务风格
- 每页不超过5个要点
- 图表清晰，数据标签完整
- 保存到桌面，文件名："2026上半年汇报_最终版.pptx"
```

### 场景4：研究竞品并生成分析报告（OPC专属）

作为OPC，你需要定期了解竞争对手的动态。让WorkBuddy帮你做：

**完整指令**：
```
帮我做一份竞品分析报告。

目标竞品：XXXX（替换为你的竞品名称）

1. 信息收集

3. 输出格式
   - 生成结构化的分析报告（Word文档）
   - 包含SWOT分析
   - 给出3条可操作的建议

4. 定时更新
   - 设置每周一上午10点自动更新
   - 如有重大更新（如产品发布、融资），立即通知我
```

## 六、常见错误与避坑

### 五个新手常犯的错误

| # | 错误 | 正确做法 |
|:-:|------|---------|
| 1 | 指令太模糊 | 说清楚：做什么数据->什么操作->输出什么格式 |
| 2 | 一个指令塞太多任务 | 分步说：先规划->确认->再执行 |
| 3 | 忘记设置定时任务 | 日常重复工作都设成定时，一劳永逸 |
| 4 | 不检查执行结果 | AI不是100%正确，关键数据要复核 |
| 5 | 装了太多技能包 | 先装3-5个核心技能用熟了再扩展 |

### 安全提醒

```text
1. 不要用WorkBuddy处理包含密码、银行卡信息的文件
2. 远程控制时注意周围环境（在公共场合慎用）
3. 定时任务涉及文件删除操作时要三思
4. 敏感数据建议先备份再让AI处理
```
