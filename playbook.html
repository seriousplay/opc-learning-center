从知道，到做到：
十步打造你的 AI 工作系统

面向所有 OPC 的行动指南：从准备、诊断、认知，到构建技能、接入知识库、整合项目——每一步都有操作动作、提示词模板、验收标准与拓展路径。跟着走，逐步提升你的 AI 驾驭力。

三个关键切换

超级个体 ≠ 会用 AI 的人。真正改变工作方式的三切换：从「自己做」→「定义任务」；从「一次性的」→「可复用的」；从「一个人」→「一个组织」。

🗺️

AI 工具地图

三类工具：通用助手（ChatGPT/Claude）· 垂直智能体（研究/写作/编程/设计）· 个人工作台（Workbuddy/IMA/Obsidian）。今天只用两三种，但知道地图在哪。

🔁

人机协作回路

五节点：输入 → AI处理 → 你的判断 → AI执行 → 你验收。人的价值：给方向、做判断、验收结果；AI 负责执行。下午亲手把它建出来。

🧱

四堵墙

为什么装了 AI 效率反而下降：习惯墙（老方法做事）· 翻译墙（说不清要什么）· 信任墙（一次不好就不用）· 整合墙（散事没串成线）。认领你卡在哪堵，今天下午拆它。

🚫

四条红线

🔴数据红线：上传前必须脱敏 ｜ 🔴外发红线：发出去前必须经你眼看 ｜ 🔴判断红线：定价/承诺/法律 AI 只给建议你拍板 ｜ 🔴质量红线：最终交付质量你说了算。

⚙️

Skill 是什么

用自然语言描述、让智能体自动构建、可反复调用的能力模块。封装了经验+判断标准+输出格式。建完不用每次重写提示词——直接调用。不需要会编程。

📚

知识库接入

技能是「通用」的，知识库让它变成「你的」。在 IMA 上传你的材料（先求最小可用：3 份跑通即可），接入技能——AI 的输出开始像你。

🏗️

项目原型

技能 + 知识库 = 你的第一个 AI 工作系统。标准只有一条：让一个真实业务任务，从输入到输出，完整地跑一次。这就是你今天的作品。

① 诊断 · 你的 AI 起点

🎯 定位基线 + 写下承诺
▸完成 AI 驾驭力测评，拿到个人诊断报告
▸识别你卡在哪堵墙：习惯/翻译/信任/整合
▸写下承诺：「本次学习结束，我最想做到的一件事是___」
🧰 工具：AI驾驭力测评（csi-org.com/workshops/ai-assessment）+ 诊断报告 🛠️ 可构建技能：基线诊断（四堵墙定位） 📈 拓展学习：四堵墙→拆墙策略：习惯墙靠定义任务·翻译墙靠澄清模板·信任墙靠验收标准·整合墙靠回路
✅ 验收标准：完成测评 + 墙定位 + 承诺

② 认知 · 三大能力

🎯 三切换 + 工具地图 + 回路
▸掌握三件事：三个关键切换 / AI工具地图 / 人机协作回路
▸对照下方知识卡片逐张消化
▸把概念映射到自己的业务场景
🧰 工具：本站 8 张知识卡片 🛠️ 可构建技能：知识卡片速读（概念→示例→自检） 📈 拓展学习：三切换→映射你的业务：哪个任务可以开始「定义任务」而不是自己做
✅ 验收标准：能讲出回路五节点

③ 案例 · 看见才相信

🎯 看清一条真实回路
▸看一段真实的人机协作回路演示（本站案例/公开演示）
▸注意：AI 执行时人在哪个节点停下说「这里不对」
▸记住一句话：人给方向、做判断、验收；AI 负责执行
🧰 工具：案例演示回放 🛠️ 可构建技能：回路拆解（识别判断节点） 📈 拓展学习：把演示中的判断节点→在自己的回路里标出来
✅ 验收标准：能指出演示中的判断节点

④ 澄清意图 · 从模糊到可执行

🎯 需求文档 + 回路草图
▸用下面模板和 AI 对话，挖清你的真实意图
▸产出：结构化任务需求文档（给谁用/解决什么/交付什么/怎么算成功）
▸画回路草图（输入→AI处理→你判断→AI执行→你验收），卡住处打问号
▸找人互检：对方能否一眼看懂你要做什么
📋 提示词模板（复制用）我有一个模糊的想法：___。请通过提问帮我把它澄清成一份结构化任务需求文档，必须包含：①给谁用 ②解决什么问题 ③最终交付什么 ④怎么算成功。先问我不清楚的地方，再输出文档。
🧰 工具：AI 对话 + 需求文档模板 🛠️ 可构建技能：意图澄清技能（四要素：给谁用/解决什么/交付什么/怎么算成功） 📈 拓展学习：需求文档→沉淀为你的可复用模板库 → 进阶：意图澄清→需求文档自动生成
✅ 验收标准：需求文档四要素齐全 + 回路草图完成

⑤ 人机分工 · 设计碳硅回路

🎯 正式回路 + 四条红线
▸把草图画实：输入（材料哪来）/AI处理（提取分析生成什么）/你的判断（哪个节点拍板？标准？）/AI执行（什么格式模板）/你验收（怎么算合格）
▸标出四条红线：数据/外发/判断/质量
▸互检：问「这个判断节点，真的需要你，还是可以交给 AI？」
📋 提示词模板（复制用）这是我要构建的人机协作回路，请帮我审查分工是否合理：输入=___，AI处理=___，我的判断=___，AI执行=___，我验收=___。请指出：哪些判断其实可以交给AI？哪些步骤缺少明确验收标准？
🧰 工具：回路画布 + 四红线清单 🛠️ 可构建技能：回路设计技能（五格+红线+验收信号） 📈 拓展学习：回路画实→下一步直接可建 → 进阶：判断节点能不能再交给 AI（人只留真判断）
✅ 验收标准：回路五格填实 + 四红线标注 + 自检🟢

⑥ 构建技能 ★核心环节

🎯 用自然语言打造专属 AI 能力
▸看演示：用自然语言让 AI 生成一个技能（如竞品分析）
▸基于意图+回路，用下面模板构建你的 skill
▸拿真实材料跑一次：跑通=AI 按你设计的逻辑处理、在该停的判断节点停下、输出符合格式
▸没跑通→复盘调整；仍失败→用兜底模板替换
📋 提示词模板（复制用）我需要一个帮我做___的技能。请先追问我几个关键问题（输入材料是什么？输出格式是什么？判断标准是什么？常见错误有哪些？），然后基于我的回答生成一个可调用的 skill。
🎯 兜底方案：3 个预置通用技能模板（内容生成类/信息整理类/客户响应类），选最接近的快速替换——不会空手而归。
🧰 工具：Workbuddy（技能构建）+ 3 预置模板 🛠️ 可构建技能：技能构建器（meta-skill：描述→追问→生成→验收） 📈 拓展学习：把常用场景都固化成技能 → 进阶：技能+知识库 → 技能市场/技能交换
✅ 验收标准：真实材料跑通 + 存档（验收标准：AI 给的结果你能用，或明确知道哪里要改）

⑦ 接入知识库 · 让 AI 懂你

🎯 技能 + 业务上下文
▸在 IMA 创建个人知识库，上传脱敏材料（先最小可用：3份跑通）
▸在技能里配置知识库接入
▸自检接入是否生效：技能调用时确实能读到知识库
📋 提示词模板（复制用）我上传了以下材料到知识库：___。请基于这些材料，调整我技能的输出风格和判断逻辑，使其符合我的业务背景。
🧰 工具：IMA（知识库）+ 脱敏材料 🛠️ 可构建技能：知识库接入技能（最小可用3份→检索调优） 📈 拓展学习：扩充到 10+ 份 → 进阶：知识库结构化（分类/标签/权限/版本）
✅ 验收标准：技能调用时能读取知识库内容

⑧ 项目原型 · 整合你的系统

🎯 技能+知识库=可运行项目
▸把技能+知识库整合成项目
▸让一个真实业务任务从输入到输出完整跑一次
▸保存、确认可调用，截图存档
🧰 工具：Workbuddy（项目整合） 🛠️ 可构建技能：项目组装技能（技能串联+知识库支撑+完整验收） 📈 拓展学习：单项目跑通 → 进阶：多项目/多技能编排 → 你的硅基团队雏形
✅ 验收标准：项目已保存可调用 + 截图

⑨ 展示 · 承诺

🎯 结构化路演 + 行动承诺
▸1.5分钟路演：你做了什么/给谁用/跑通没有
▸写 72 小时行动卡：72小时内用今天建的技能处理一件真实工作
▸找见证人签名，存档
🧰 工具：路演卡 + 72小时行动卡 🛠️ 可构建技能：作品路演（1.5分钟结构化表达：做了什么/给谁用/跑通没有） 📈 拓展学习：定期复盘 → 作品集沉淀为你的案例库
✅ 验收标准：行动卡完成 + 见证人签名

⑩ 复盘 · 灵魂三问

🎯 回望承诺，锚定意义
▸回看你的承诺：你做到了吗？
▸灵魂三问：省下来的时间，去做更多同样的事 / 去做以前做不到的事 / 去做一直想做但没时间做的事
▸记住：你不再是一个人完成所有任务——你是在设计任务、分配任务、确认任务。你是一家公司。
🧰 工具：复盘框架 + 反馈表 🛠️ 可构建技能：复盘技能（灵魂三问框架） 📈 拓展学习：30天路线图（觉醒→固化→组装→放大）→ 进阶：把回路变产品、把能力变收入
✅ 验收标准：完成三问 + 填写复盘
🧭 核心提醒：工具链爬得高不是目的，组装成能跑的自闭环回路才是。跑通的标准：AI 给的结果你能用，或明确知道哪里要改。
TOOL SETUP

工具准备与数据安全

课前3天装好三件套，现场直接进入状态。数据红线第一条：先脱敏，再上传。

⚡

Workbuddy（主平台）

今天的主战场：构建技能、整合项目都在这里。课前3天按指南安装注册，现场需要登录态。

📚

IMA（知识库）

模块⑦使用：创建个人知识库，上传你的脱敏材料。先求最小可用——3份就能跑通。

🗂️

Obsidian（可选）

个人知识管理的持续记录本。今天把技能清单/回路画布/操作说明存进去，作为你个人AI系统的记录。没有也不影响。

🔒

数据安全 · 脱敏

不能传：客户资料/合同原文/医疗法律财务敏感数据/可识别身份信息。能传：脱敏后保留逻辑与结构的业务内容。做法：客户名换代号、联系方式删除、金额模糊化（约10万级）、敏感条款只留结构。不确定先问教练。
