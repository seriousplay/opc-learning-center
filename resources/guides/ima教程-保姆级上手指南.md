## 一、这是什么工具？

**ima** 是腾讯推出的AI知识管家（AI PKM），集搜索、阅读、写作于一体。你可以把它理解为：**你的"第二大脑"——所有有价值的信息存进去，AI帮你记住、理解、输出。**

### 核心能力

| 能力 | 一句话说明 |
|------|-----------|
| AI问答 | 问你的知识库，像问一个熟悉你所有资料的专家 |
| 多格式导入 | PDF/Word/图片/微信文章一键存入 |
| 文档解读 | 自动摘要、提取核心观点、深度问答 |
| AI写作 | 基于你的知识库起草论文/文案/报告 |
| 知识Agent | 把你的知识库变成可订阅的"知识号" |
| 知识库广场 | 公开发布知识库，让别人订阅你的内容 |
| 微信生态 | 微信文章一秒导入，小程序随时查看 |

### ima vs 其他笔记工具

| 对比 | ima | Notion | Obsidian | 飞书文档 |
|------|-----|--------|----------|---------|
| AI问答 | 基于知识库深度问答 | 弱 | 需要插件 | 基础 |
| 微信导入 | 一键（右上角->ima） | 无 | 无 | 弱 |
| 知识库发布 | 知识号+广场（可订阅） | 可分享 | 需插件 | 可分享 |
| 离线使用 | 部分支持 | 支持 | 强 | 支持 |
| 学习成本 | 极低 | 中 | 高 | 中 |

## 二、安装与设置（3分钟上手）

### 2.1 获取方式（三端同步）

```text
PC端：
  官网 ima.qq.com 下载桌面版（macOS/Windows）
  或直接在浏览器打开 ima.qq.com

手机端：
  微信搜索小程序 "ima知识库"

APP端：
  应用商店搜索 "ima"
```

> 三个端数据完全同步，手机上看到的在电脑上也能看到。

### 2.2 首次设置

```text
1. 用微信登录（最简单，不用注册新账号）
2. 选择你感兴趣的知识领域（后续可改）
3. 系统会自动推荐一些公开知识库，可以订阅看看
```

### 2.3 微信导入设置（关键一步）

这是ima最方便的功能——看公众号文章时一键导入：

```text
1. 在微信中打开任意公众号文章
2. 点击右上角的「...」
3. 选择「更多打开方式」
4. 选择「ima知识库」
5. 文章自动存入你的知识库
```

> 养成习惯：看到好文章就点一下，积累你的"第二大脑"。

## 三、核心功能与使用方式

### 3.1 知识库（核心中的核心）

知识库是ima的基石。所有导入的资料都放在知识库里。

**两种知识库类型**：

| 类型 | 说明 | 用途 |
|------|------|------|
| 个人知识库 | 只有你自己能看 | 私人笔记、学习资料 |
| 共享知识库 | 可发布/邀请他人 | 公开内容、团队协作 |

**创建知识库**：
```text
1. 点击左侧「知识库」
2. 「创建知识库」
3. 填写名称和描述
4. 选择类型（个人/共享/订阅）
```

### 3.2 内容导入（6种方式）

| 方式 | 操作 | 适用场景 |
|------|------|---------|
| 微信文章导入 | 右上角->更多打开方式->ima | 日常阅读积累 |
| 上传文件 | 拖拽或选择PDF/Word/PPT/图片 | 报告、合同、教材 |
| 网页链接 | 粘贴URL自动导入 | 网页文章收藏 |
| 拍照识别 | APP拍照自动OCR | 纸质文件数字化 |
| 截图导入 | 截图后直接拖入 | 临时信息记录 |
| 手动笔记 | 直接输入或粘贴 | 自己的想法和总结 |

### 3.3 AI问答

这是ima与普通笔记软件最大的区别——你不用"找到"信息，直接"问"就行。

```text
普通笔记软件：打开文件夹 -> 找到文件 -> 搜索关键词 -> 逐篇阅读
ima：直接问 → AI从你的知识库中找到答案

# 例子
问："去年我们做的那个客户案例，核心数据是什么？"
AI从你存入的案例文档中找到答案，并标注来源
```

**标签筛选**：用 `#标签名` 可以限定AI只搜索某个分类的内容。

### 3.4 AI写作

基于你的知识库内容进行写作，不是空洞的AI生成：

```text
"基于我知识库里的OPC案例，写一篇公众号推文"
→ AI会从你存的Pieter Levels、Justin Welsh等案例中提取素材
→ 生成一篇有具体数据、有案例支撑的文章
→ 而不是泛泛的AI套话
```

### 3.5 知识Agent（Copilot）

2026年4月推出的重磅功能——把你的知识库变成一个"知识号"，别人可以直接订阅。

```text
1. 打开你的知识库
2. 启用「知识Agent」
3. 设置知识号名称、头像、描述
4. 发布后，别人可以搜索到并订阅

你的知识Agent会：
- 基于你的知识库内容回答订阅者的问题
- 就像你请了一个"AI小编"替你值班
```

## 四、正确使用姿势（精华）

### 4.1 知识库架构设计

**错误做法**：把所有东西塞到一个知识库。

**正确做法**：按主题划分多个知识库。

```
好的结构示例：
├── AI原生组织全球实践     ← 公开订阅库，面向读者
├── OPC超级个体加速器      ← 公开订阅库，面向OPC创业者
├── 个人学习笔记           ← 私人库，自己消化
├── 项目管理               ← 团队共享库，项目协作
└── 书稿素材库             ← 私人库，写作素材
```

**每个知识库配6个文件夹**，按内容类型分栏，让读者一目了然。

### 4.2 内容分类原则

| 知识库中的文件夹 | 放什么 |
|-----------------|--------|
| 栏目一：入门必读 | 概念、框架、思维转变 |
| 栏目二：能力建设 | 技能、方法论、工具 |
| 栏目三：案例 | 他人经验、复盘 |
| 栏目四：工具箱 | 模板、checklist、脚本 |
| 栏目五：商业化 | 产品、定价、获客 |
| 栏目六：持续成长 | 社群、资源 |

### 4.3 内容命名规范

好标题 = 好检索。建议统一格式：

```text
【类型】主题：一句话看点

# 例子
【案例】Pieter Levels：从0到$165万ARR的极简技术栈创业
【工具】Cursor：2026年最值得入手的AI IDE
【方法论】OPC冷启动三步法：验证 -> 付费 -> 规模化
【每周精选】AI编程工具2026横向对比
```

### 4.4 AI问答小技巧

写公众号文章时直接：`#素材` + `#AI原生组织` 两个标签交叉筛选。

```
# 基础用法
"#标签 你的问题"
例："#案例 有哪些OPC年收入过百万？"

# 进阶用法：结合多个标签
"#案例 #AI工具 这些AI工具公司怎么赚钱的？"

# 深度用法：让AI对比分析
"#案例 对比Pieter Levels和Justin Welsh的商业模式差异"
```

## 五、实战场景（含完整指令）

### 场景1：日常信息收藏与消化

作为OPC，每天会看到大量文章、报告、信息。用ima建立"收-整-用"循环：

**收藏阶段**（每天随手做）：
```
看到好文章 -> 微信右上角 -> 更多打开方式 -> ima知识库
看到好内容 -> 复制链接 -> 粘贴到ima -> 自动导入
```

**整理阶段**（每周一次）：
```
在ima搜索框中输入：
"#本周新增 帮我总结这周存入的所有文章的核心观点"

AI会自动：
- 提取每篇的3-5个要点
- 识别重复内容
- 给出交叉关联
- 标记值得精读的文章
```

**输出阶段**（需要时）：
```
"基于我知识库里的案例素材，写一篇关于'OPC如何选择AI工具'的文章"
```

### 场景2：用知识库做深度研究

这是NotebookLM + ima的黄金组合：

**研究流程**：
```text
Step 1：NotebookLM做深度研究
  → 获得结构化的研究报告

Step 2：研究报告导入ima
  → 上传到对应知识库的研究文件夹

Step 3：ima消化产出
  → 问AI："这份报告里Pieter Levels的商业模式核心是什么？"
  → AI基于报告内容回答，并标注信源

Step 4：写作输出
  → "基于这份研究报告，写一篇HBR风格的案例笔记"
  → AI产出初稿，你精修
```

### 场景3：管理多个知识库的知识Agent

如果你运营多个公开知识库（比如同时运营AI原生组织和OPC加速器），每个知识库都可以独立设置知识Agent，相当于请了多个"AI小编"分别值班。

**配置建议**：
```text
知识库A：AI原生组织全球实践
  Agent定位：讲AI原生组织趋势和案例
  回答风格：专业、HBR规格

知识库B：OPC超级个体加速器
  Agent定位：教人如何做OPC创业
  回答风格：实战派、有具体操作方法
```

> 设置路径：每个知识库的设置页 -> 知识Agent -> 启用 + 设置风格

### 场景4：用ima做公众号内容生产

从ima直接完成"研究->写作->发布"全流程：

```text
指令到ima：
"基于#案例标签里的内容，
写一篇关于Chatbase创始人Yasser Elsaid的公众号文章，
风格：分析深度+故事感，
字数：2000-3000字，
结构：开头导语->核心数据->成长故事->商业模式->启示->结尾"

ima会：
1. 从你存的Chatbase案例文档中提取素材
2. 按HBR风格组织内容
3. 生成初稿
4. 你精修后发布到公众号
```

## 六、常见错误与避坑

### 六个新手常犯的错误

| # | 错误 | 正确做法 |
|:-:|------|---------|
| 1 | 只收藏不整理 | 每周花10分钟给新内容打标签、分类 |
| 2 | 标题太模糊 | 用【类型】+ 主题 + 看点的命名格式 |
| 3 | 一个知识库塞所有 | 按主题分多个库，每个库不超过100篇 |
| 4 | 不利用AI问答 | 别手动翻，直接问AI更快 |
| 5 | 从不清理过期内容 | 每月review一次，删掉过时的 |
| 6 | 忽略标签功能 | 打标签比分类更灵活，多用 # 标签 |

### 实际使用中发现的坑

```text
1. 文件夹创建只能在界面操作，API不支持
   → 建库时先把文件夹结构搭好再开始填内容

2. 笔记标题不能超过一定长度
   → 超过120字会截断，保持标题简洁

3. 知识库描述要写清楚
   → 新读者通过描述决定是否订阅

4. AI问答依赖知识库内容的完整性
   → 资料越全，回答越准，别只存一半
```
