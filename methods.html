八大工作法

每个方法 = 核心步骤 + 代表工具 + 一句最佳实践。方法比工具重要：先掌握方法，工具只是方法的手。

🔬 深度研究法

多源搜索 → 信源验证 → 交叉确认 → 结构化输出
1.用 Perplexity / Gemini Notebook 做多源检索，形成研究骨架
2.回到原文：至少 2 家独立信源交叉验证，数字逐字对照原文
3.把验证后的内容沉淀进知识库，标注信源与日期
4.结构化输出：框架化、带引用、可复用
🛠️ 核心技能：研究简报技能：多源检索 → 信源验证 → 结构化简报（带引用+标注日期） 🧰 工具链：Perplexity（检索入口）→ Gemini Notebook（深度研究）→ 研究知识库（沉淀） 📈 拓展学习：进阶：研究流程固化为技能 → 接入知识库 → 升级为「自动研究Agent」：触发→检索→验证→简报→自动入库
🧰 代表工具：Perplexity.ai · Gemini Notebook（原 NotebookLM）· 原文/官方文档💡 铁律：NotebookLM / LLM 摘要只作选题线索，绝不直接作为信源。

✍️ AI 协作写作法

人机共创 → 多智能体审阅 → 迭代打磨
1.人定框架与立场，AI 出第一稿素材
2.多智能体并行审阅（创意/读者/编辑三视角），输出原始反馈
3.你对照反馈逐条修订——AI 不替你决定，替你放大判断
4.事实核查 + 风格统一后定稿
🛠️ 核心技能：写作风格技能：人设+语气+禁语+结构模板，一次定义反复调用 🧰 工具链：Claude（主写）→ 多智能体审阅（创意/读者/编辑）→ 发布管道（公众号/星球） 📈 拓展学习：进阶：风格技能+知识库=「你的内容工厂」→ 多智能体评审闭环 → 定时自动生产+人工把关
🧰 代表工具：Claude · ChatGPT · 多智能体审阅工作流 · 公众号爆款结构💡 人机协同写作的正确姿势：AI 负责速度，你负责标准。

🧠 第二大脑法

输入低摩擦 → 核心 AI 内化 → 输出最短路径
1.输入：信息自动流入（RSS/订阅/同步），降低采集摩擦
2.核心：Obsidian/IMA 连接知识，AI 加速内化（问答/摘要/提炼）
3.输出：从笔记到成品距离越短越好——笔记即草稿
4.定期巡检：清理孤岛笔记、死链接、观点矛盾
🛠️ 核心技能：笔记整理技能：自动分类+要点提炼+双向链接，让知识自动长成网 🧰 工具链：Obsidian（存储）→ IMA（AI问答）→ Gemini Notebook（研究）→ RSS 同步（输入） 📈 拓展学习：进阶：笔记自动流入→AI提炼→定期巡检（孤岛/死链/矛盾）→ 知识库成为你的数字分身
🧰 代表工具：Obsidian · IMA · Gemini Notebook · 飞书知识库💡 知识工作流三层架构：输入降摩擦，核心用 AI 连接，输出走最短路径。

🎙️ 会议效率法

自动纪要 → 待办提取 → 摘要分发
1.AI 自动转录并生成会议纪要（飞书妙记等）
2.自动提取待办事项与负责人，同步到任务系统
3.生成「与我相关」的个性化摘要，而不是全文转发
4.会前用 AI 聚合资料，会中只做判断
🛠️ 核心技能：会议纪要技能：转录→纪要→待办提取→定向分发 🧰 工具链：飞书妙记（转录）→ Lindy（行政自动化）→ 任务系统同步 → 日历聚合 📈 拓展学习：进阶：纪要→待办自动同步任务系统 → 会前AI聚合资料 → 会议只做判断
🧰 代表工具：飞书妙记 · Lindy（AI 行政助理）· 通义听悟类工具💡 会议的最高产出不是纪要，是决策与待办——让 AI 承担记录，人承担判断。

📄 文档处理法

2026 知识工作者 ROI 最高的场景
1.合同/协议审查：AI 提取条款、标出风险点
2.发票/单据提取：结构化数据自动入库
3.报告生成：数据入 → 结构化报告出
4.人只做最后签字确认与判断
🛠️ 核心技能：文档审查技能：条款提取+风险标注+修改建议（一页纸摘要） 🧰 工具链：Claude/GPT（审查）→ 文档解析工具 → n8n（流水线）→ 文档知识库 📈 拓展学习：进阶：合同/发票/报告流水线自动化 → 异常标记人复核 → 覆盖全类型文档
🧰 代表工具：Claude/GPT 类模型 · 文档解析工具 · n8n 流水线💡 文档处理、报告生成是 2026 年回报最清晰的知识工作 AI 应用。

📊 数据分析法

报表自动化 → 财务自动化 → 决策支持
1.数据接入：表格/数据库/API 自动同步
2.AI 生成周报月报：结构固定、数据自动填充
3.异常检测：AI 标记偏离，人只看异常
4.沉淀指标体系，越用越准
🛠️ 核心技能：周报生成技能：数据接入→结构固定→异常标记→决策摘要 🧰 工具链：飞书多维表格（数据）→ n8n（自动同步）→ AI 报表 → 仪表盘 📈 拓展学习：进阶：报表结构固化→数据自动填充→异常检测→决策支持仪表盘
🧰 代表工具：飞书多维表格 · n8n · AI 报表工具 · Excel/Python 脚本💡 先固定报表结构，再接入自动化——AI 填数，人看异常与方向。

⚙️ 自动化法

识别重复 → 搭建工作流 → 无人值守
1.盘点：列出每周重复 3 次以上的操作
2.从低代码开始：飞书多维表格 / Zapier 搭建第一条流水线
3.升级到 n8n：自部署、无限量、4000+ 社区模板
4.加上 AI 步骤：让自动化拥有判断能力
🛠️ 核心技能：流程自动化技能：触发条件+执行步骤+异常处理+运行日志 🧰 工具链：飞书多维表格（零门槛）→ Zapier（快速连接）→ n8n（无限量/自部署） 📈 拓展学习：进阶：加AI节点让流水线有判断 → 多流程编排 → 无人值守业务
🧰 代表工具：n8n · Make · Zapier · 飞书多维表格自动化 · Pipedream💡 自动化三剑客：n8n（无限量）+ Claude Code（复杂任务）+ 营销/行政 AI。

🤖 Agent 构建法

2026 最值钱技能：管理 AI 智能体
1.从提示词固化开始：跑通的流程沉淀为技能
2.构建单 Agent：明确职责、输入输出、不做清单
3.接知识库：给 Agent 动态上下文
4.多智能体编排：分工协作，人做仲裁与决策
🛠️ 核心技能：Agent定义技能：职责边界+输入输出+不做清单+验收标准 🧰 工具链：Coze（快速Bot）→ Dify（深度定制）→ Claude Code（复杂任务）→ 自建编排（Hermes等） 📈 拓展学习：进阶：单Agent→技能固化→知识库接入→多智能体编排→你成为 Orchestrator
🧰 代表工具：Coze（扣子）· Dify · Claude Code · n8n · 自建编排💡 工具链爬得高不是目的，组装成「自闭环回路」才是。每天问：今天哪件事能再往上爬一层？
🧭 方法论优先级：先从与你工作重合度最高的 1-2 条入手，跑通后再扩展。贪多嚼不烂——渐进式升级的核心是「往上爬一层」。
